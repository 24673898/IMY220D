# FrankCodeHub - IMY220D Project

## Setup and Run

**1. Clone the repository**
```bash
git clone https://github.com/24673898/IMY220D.git
cd IMY220D
```
**3. Open docker desktop**

**4. Run with Docker**
```bash
docker-compose up --build
```

**5. Open the application**
```
http://localhost:3000
```

## Stop the application
```bash
docker-compose down
```
